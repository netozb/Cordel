# Exemplos

Programas prontos para rodar, estudar e modificar. Todos seguem o formato oficial e rodam sem avisos, menos `erros.cordel`, que tem erros de propósito.

| Arquivo | O que faz | Como abrir |
|---|---|---|
| `tour.cordel` | Tour rápido | `cordel rodar exemplos/tour.cordel` |
| `tarefas.cordel` | Lista de tarefas (app) | `cordel app exemplos/tarefas.cordel` |
| `parcelas.cordel` | Simulador de parcelas (app) | `cordel app exemplos/parcelas.cordel` |
| `site.cordel` | Página de apresentação (site) | `cordel app exemplos/site.cordel` |
| `painel.cordel` | Painel de vendas (app) | `cordel app exemplos/painel.cordel` |
| `catalogo.cordel` | Catálogo com páginas (app) | `cordel app exemplos/catalogo.cordel` |
| `prazos.cordel` | Prazos e vencimentos | `cordel rodar exemplos/prazos.cordel` |
| `auditoria.cordel` | Auditoria de planilha | `cordel rodar exemplos/auditoria.cordel` |
| `conciliacao.cordel` | Conciliação de vendas com o extrato | `cordel rodar exemplos/conciliacao.cordel` |
| `horarios.cordel` | Horários na auditoria | `cordel rodar exemplos/horarios.cordel` |
| `regras.cordel` | Regras de auditoria | módulo: `use "regras"` em `auditoria.cordel` |
| `cnpj.cordel` | Consulta de CNPJ (app, usa a internet) | `cordel app exemplos/cnpj.cordel` |
| `caixa.cordel` | Conferência de caixa | `cordel rodar exemplos/caixa.cordel` |
| `dinheiro.cordel` | Parcelas, rateio e juros | `cordel rodar exemplos/dinheiro.cordel` |
| `testes.cordel` | Testes embutidos | `cordel testar exemplos/testes.cordel` |
| `adivinha.cordel` | Jogo de adivinhação (faz perguntas) | `cordel rodar exemplos/adivinha.cordel` |
| `pergunte.cordel` | Pergunte e responda (faz perguntas) | `cordel rodar exemplos/pergunte.cordel` |
| `estrofe.cordel` | Estrofe de cordel | `cordel rodar exemplos/estrofe.cordel` |
| `erros.cordel` | Erros que ensinam | `cordel verificar exemplos/erros.cordel` |

As planilhas `vendas_exemplo.csv` e `extrato_exemplo.csv` ficam nesta mesma pasta, e os exemplos as acham sozinhos.
